# ТЕХНОЛАБАЛМАЗ — статический лендинг

Одностраничный сайт на HTML и CSS. Откройте `index.html` в браузере или разместите содержимое папки на статическом хостинге.

## Состав

- `index.html` — разметка и текст лендинга.
- `styles.css` — адаптивные стили.
- `assets/technolab-almaz-logo.png` — предоставленный логотип с прозрачным фоном.
- `assets/injector-hero.png` — сгенерированное изображение для первого экрана.
- `assets/precision-pair-background.png` — сгенерированный фотобэкграунд блока «Прецизионная пара».

Montserrat подключается через Google Fonts, Tabler Icons — через jsDelivr. Для их загрузки требуется интернет-соединение.

Диапазон 500–1600 моточасов на странице обозначает исходное описание ресурса форсунок, а увеличение ресурса — цель разработки, не измеренный результат.
